# 졸업생 표창 대상자 추천 명단 취합

학교에서 제출한 「졸업생 표창 대상자 추천 명단(서식)」 엑셀 파일 여러 개를 올리면, 시트(교육감표창 초·중·고·특)별로 한 파일에 모아 주는 웹페이지입니다.

- 파일은 **브라우저 안에서만** 처리되며 서버로 전송되지 않습니다. (GitHub Pages는 정적 파일만 제공)
- 설치 없이 크롬·엣지·웨일에서 바로 사용할 수 있습니다.

## 사용 방법

1. 페이지를 열고 학교에서 받은 `.xlsx` 파일들을 끌어다 놓습니다. (여러 개 한꺼번에 가능)
2. ‘업로드한 파일’ 표에서 학교별·시트별 인원을 확인합니다.
3. ‘확인이 필요한 항목’에서 빈 칸, 공적개요 글자 수(50~100자), 생년월일 형식, 중복 의심 등을 확인합니다.
4. **취합 엑셀 내려받기**를 누르면 서식과 같은 모양의 취합 파일이 저장됩니다.

## 처리 규칙

| 항목 | 동작 |
| --- | --- |
| 시트 | 시트 이름이 같은 것끼리 모음. 이름에 ‘예시’가 들어간 시트, 숨긴 시트는 건너뜀 |
| 열 찾기 | 헤더 글자(연번·지역·학교급·학교명·학년·성명·성별·생년월일·일시·장소·공적)로 찾음. 열 순서가 조금 달라도 동작 |
| 예시 행 | 학교명이 `OO`, `○○`, `00` 등으로 시작하는 행은 제외 (옵션) |
| 12월 졸업식 | 원본에 음영이 있거나 일시가 12월이면 일시 칸에 노란색 음영 (옵션) |
| 생년월일 | `2008.1.5`, `2008-01-05`, `20080105` 등을 `2008.01.05`로 맞춤 |
| 정렬·연번 | 학교명 가나다순 정렬(옵션) 후 연번을 1부터 다시 매김 |
| 취합현황 | 마지막 시트에 파일별·시트별 인원과 확인 필요 건수 정리 (옵션) |

> `.xls`(예전 형식) 파일은 엑셀에서 *Excel 통합 문서(.xlsx)* 로 다시 저장한 뒤 올려 주세요.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 push 합니다.
2. 저장소 **Settings → Pages → Build and deployment** 에서 Source를 *Deploy from a branch*, Branch를 `main` / `(root)` 로 지정합니다.
3. 1~2분 뒤 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

## 로컬에서 실행

```bash
python -m http.server 8765
```

브라우저에서 <http://localhost:8765> 를 엽니다.
